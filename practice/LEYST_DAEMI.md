# Leyst dæmi

Hér fara aðeins dæmi sem hafa verið unnin og skilin skref fyrir skref.

## Algebra

### 1. Einföld jafna
`4x - 7 = 13`

`4x = 20`

`x = 5`

### 2. Svigar
`4(x + 2) = 20`

`4x + 8 = 20`

`4x = 12`

`x = 3`

### 3. x báðum megin
`5x + 2 = 3x + 10`

`5x = 3x + 8`

`2x = 8`

`x = 4`

### 4. Einangra Q
`P = 7Q + 21`

`P - 21 = 7Q`

`Q = (P - 21) / 7`

## Brot

### 5. Samlagning
`1/2 + 1/3`

`3/6 + 2/6 = 5/6`

### 6. Frádráttur
`3/4 - 1/6`

`9/12 - 2/12 = 7/12`

### 7. Margföldun
`4/7 × 3/8 = 12/56 = 3/14`

### 8. Deiling
`3/4 ÷ 2/5`

`3/4 × 5/2 = 15/8`
