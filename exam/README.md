# Prófundirbúningur

Þessi mappa verður byggð upp jafnt og þétt meðan á náminu stendur.

## Fyrirhuguð skjöl
- `FORMULUBLAD.md` – formúlur og stuttar skýringar.
- `ADALREGLUR.md` – vinnureglur og algengar gildrur.
- `DAEMAGERDIR.md` – dæmagerðir og lausnarferli.
- `PROFAEFINGAR.md` – blönduð prófdæmi og æfingar.

## Regla
Ekki setja efni hér eingöngu af því að það hefur komið fyrir í glærum. Efnið á að vera unnið þannig að hægt sé að nota það hratt og örugglega við prófundirbúning.
