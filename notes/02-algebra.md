# Grunnalgebra – vinnuglósur

## Meginregla í jöfnum
Gerðu **sömu aðgerð báðum megin** þar til breytan stendur ein.

Dæmi:

`3x + 5 = 20`

`3x = 15`

`x = 5`

## Margfalda inn í sviga
Talan fyrir utan svigann margfaldast með **hverjum lið** inni í sviganum.

`2(x + 3) = 2x + 6`

## Formerki
Ekki hugsa eingöngu „færa yfir og skipta um formerki“. Skrifa aðgerðina:

`5 - 2x = 17`

`-2x = 17 - 5`

`-2x = 12`

`x = -6`

## x báðum megin
`5x + 2 = 3x + 10`

`5x = 3x + 8`

`2x = 8`

`x = 4`

## Einangra Q
Grunnform:

`P = aQ + b`

1. Draga `b` frá báðum megin.
2. Deila öllu með `a`.

Dæmi:

`P = 7Q + 21`

`P - 21 = 7Q`

`Q = (P - 21) / 7`

## Mikilvæg vinnuregla
**Eitt skref í hverri línu.** Þetta minnkar fljótfærnisvillur verulega.
